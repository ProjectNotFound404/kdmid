# Repository Discoverability

## Public identity

Use the consistent product name **КД МИД — мои люди / KDMID — My People**. The canonical source is https://github.com/ProjectNotFound404/kdmid. It is a free, unofficial, open-source Chrome extension for reusing person details in notarial applications on `notary.kdmid.ru`, including consular powers of attorney. It saves multiple local profiles, encrypts saved data and new backups, and fills the current natural-person form after a user click. It does not book appointments, draft document text, or register applications.

The Russian and English READMEs include practical questions and direct answers about passport autofill, principals and representatives, Russian consulates, privacy, and transfers between computers. Keep these answers aligned with actual features rather than adding repeated keyword lists.
