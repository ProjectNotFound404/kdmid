# КД МИД — автозаполнение данных людей в нотариальных заявлениях

**Русский** | [English](README.en.md)

**КД МИД — мои люди** — бесплатное расширение Chrome с открытым исходным кодом для автозаполнения персональных данных участников нотариальных заявлений на [notary.kdmid.ru](https://notary.kdmid.ru/), портале Консульского департамента МИД России. Помогает повторно использовать ФИО, паспортные данные и адреса доверителя и поверенного при подготовке доверенностей для российских консульств за границей.

Введите данные каждого человека один раз, сохраните профиль в расширении и выбирайте его в открытой форме участника. Персональные данные хранятся в зашифрованном виде в вашем профиле Chrome на вашем компьютере. Разработчик не получает профили, пароль или ключ шифрования; данные не хранятся на его серверах и не отправляются ему, в облачные API или аналитику. Для автозаполнения расширение расшифровывает профиль локально после разблокировки, а данные попадают на официальный портал только после нажатия **Заполнить**. Для работы не нужны аккаунт приложения, сервер, Docker, ChatGPT, Claude или внешние API. Само заполнение выполняется обычным JavaScript, без ИИ.

## Для каких задач подходит

- Заполнить паспортные данные доверителя или поверенного в нотариальном заявлении на `notary.kdmid.ru`.
- Сохранить данные нескольких людей и использовать их при оформлении новых доверенностей в консульстве.
- Повторно заполнить форму физического лица, выбрав готовый профиль вместо ручного ввода ФИО, документа и адреса.
- Перенести сохранённые профили на другой компьютер через локальный зашифрованный экспорт и импорт JSON.

Это независимый неофициальный помощник. Расширение заполняет поля человека; текст доверенности, выбор консульства, запись на приём и регистрация заявления остаются отдельными действиями пользователя на соответствующих официальных ресурсах.

## Частые вопросы

### Как не вводить паспортные данные заново на notary.kdmid.ru?

Сохраните человека в расширении **КД МИД — мои люди**. В следующем нотариальном заявлении выберите тип участника на портале, откройте форму физического лица и нажмите **Заполнить**, выбрав сохранённый профиль. Повторно вводить ФИО, документ и адрес не нужно.

### Можно ли хранить разных доверителей и поверенных?

Да. Добавьте отдельный профиль для каждого человека. Один профиль можно использовать в разных заявлениях и ролях; роль доверителя, поверенного или другого участника выбирается на портале перед заполнением.

### Подходит ли расширение для доверенности в российском консульстве?

Да, для заполнения персональных данных участников заявления на `notary.kdmid.ru`. Текст доверенности готовится отдельно. Расширение не записывает на консульский приём, не регистрирует заявления и не является официальным сервисом МИД.

### Куда отправляются паспортные данные? Используется ли ИИ?

Разработчик не получает профили. Они хранятся зашифрованными на вашем компьютере; ИИ, облачные API и аналитика не используются. После вашего нажатия **Заполнить** данные появляются в форме официального портала, где их могут прочитать его скрипты. Подробности — в [политике конфиденциальности](PRIVACY.md).

### Можно ли перенести людей на другой компьютер?

Да. Экспортируйте зашифрованный JSON, перенесите файл и импортируйте его с паролем, действовавшим при экспорте. Введённые ранее незашифрованные резервные копии также можно импортировать. Удаление расширения очищает его хранилище, поэтому сначала сделайте экспорт.

### Расширение бесплатное и с открытым кодом?

Да. Исходный код доступен в [ProjectNotFound404/kdmid](https://github.com/ProjectNotFound404/kdmid), лицензия — MIT. Нужен настольный Chrome; сервер, Docker и аккаунт приложения не требуются.

## Как пользоваться

1. Откройте расширение → **Мои люди — добавить или изменить**.
2. При первом запуске задайте пароль хранилища от 12 символов. Уже сохранённые люди перенесутся автоматически. Затем введите данные человека и нажмите **Сохранить человека**. Добавьте остальных людей таким же способом.
3. На портале выберите тип участника и откройте форму его персональных данных.
4. Нажмите значок расширения, выберите сохранённого человека → **Заполнить**.
5. Проверьте поля и самостоятельно нажмите **Добавить** на портале.

Расширение заполняет открытую форму физического лица. Выбор роли участника, переходы между страницами и регистрация заявления выполняются на самом портале.

В поле **Страна адреса** есть выпадающий список с поиском: 205 вариантов, считанных с портала 09.10.2026. Написание, значения и порядок сохранены. Выберите полное название страны — незавершённый поисковый запрос сохранить нельзя. Ранее введённые страны распознаются без учёта регистра. Если старое название не найдено в списке, оно остаётся в записи и его можно исправить, сохранив остальные данные человека.

## Установка

Для работы нужен настольный Chrome. Docker, сервер и установка зависимостей не требуются.

1. Скачайте этот репозиторий через **Code → Download ZIP** и распакуйте архив либо клонируйте репозиторий.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика** справа сверху.
4. Нажмите **Загрузить распакованное расширение** и выберите папку `extension/`, в которой находится `manifest.json`.
5. Закрепите **КД МИД — мои люди** через меню расширений Chrome.

Прототип пока не опубликован в Chrome Web Store. Инструкция для разработчика: [публикация в Chrome Web Store](docs/chrome-web-store.md).

## Обновление

Обновите файлы в той же папке, из которой установлено расширение, и нажмите значок перезагрузки на `chrome://extensions`. Затем заново откройте или обновите вкладку **Мои люди**.

**Не удаляйте расширение для обновления:** удаление очищает его локальное хранилище. Сохранение прежней папки и установленной копии позволяет сохранить профили людей.

## Экспорт и импорт людей

В разблокированном разделе **Мои люди** нажмите **Экспорт людей** — браузер скачает JSON с зашифрованными сохранёнными профилями. Перед экспортом сохраните текущие изменения: несохранённые правки в файл не входят.

Для восстановления сначала введите **Пароль импортируемого файла**, действовавший при экспорте, затем нажмите **Импорт людей** и выберите файл. Пароль текущего хранилища может отличаться. Импорт проверяет весь файл перед записью, сохраняет существующих людей и пропускает совпадающие профили. Если идентификатор совпадает, а данные отличаются, импортированная запись получает новый идентификатор. Несохранённые изменения в редакторе остаются на месте.

Новый формат резервной копии — `kdmid-encrypted-vault`, версия 1. Старые незашифрованные файлы `kdmid-person-profiles` версии 1 также импортируются, без пароля файла. Максимум — 10 МБ для зашифрованного файла, 5 МБ для старого формата и 1000 людей в хранилище; действует также квота Chrome.

**Сохраните пароль: без него новый экспорт восстановить нельзя.** Старые скачанные файлы остаются незашифрованными; обновление расширения их не изменяет. Храните резервные копии вне репозитория. Сделайте экспорт перед удалением расширения или переносом на другой компьютер.

## Хранение данных и доступ к странице

Профили хранятся локально в `chrome.storage.local` в зашифрованном виде: AES-256-GCM с новым случайным IV при каждой записи. Ключ выводится из пароля через PBKDF2-SHA256 (600 000 итераций, случайная соль). Пароль не сохраняется. Chrome Sync не используется.

После разблокировки ключ временно находится в `chrome.storage.session`, которое Chrome держит в памяти, с доступом только из доверенных контекстов расширения. Хранилище блокируется после перезапуска, перезагрузки расширения или 15 минут бездействия; его можно заблокировать кнопкой. Открытые списки и формы очищаются, включая несохранённые правки. Обработка хранилища идёт через service worker с последовательной записью, чтобы параллельные вкладки не затирали профили.

**Забытый пароль восстановить нельзя.** Выбирайте уникальную длинную парольную фразу и храните её в менеджере паролей. Шифрование защищает сохранённые данные и новые экспорты, но не защищает от вредоносного ПО или доступа к уже разблокированному браузеру. Перенос старых записей не гарантирует стирания прежних копий с диска и из резервных копий Chrome.

У расширения нет собственного сервера, аналитики и внешних библиотек; оно не выполняет собственных сетевых запросов. После нажатия **Заполнить** выбранные данные попадают в поля официального портала и становятся доступны его скриптам. Chrome и портал работают с сетью самостоятельно.

Разрешение `activeTab` даёт временный доступ к странице после открытия расширения, `scripting` используется для заполнения, `storage` — для локального хранилища, `alarms` — для автоматической блокировки. Перед заполнением проверяются точный HTTPS-адрес портала и наличие одной видимой формы человека.

Если в форме уже есть отличающиеся данные, расширение попросит подтвердить замену. При подтверждённой замене доступные поля, пустые в выбранном профиле, также очищаются, чтобы не смешивать сведения разных людей. О недоступных или неподдерживаемых полях появится сообщение. Пароли портала, номера заявлений, согласия и тексты документов расширение не читает и не изменяет.

## Разработка

Исходники находятся в `extension/`, тесты — в `tests/`. Используются JavaScript с ES-модулями и отступами в два пробела, без фреймворка сборки.

```sh
npm ci
npm run check
npm test
npm run package
```

Последняя команда создаёт два архива в `dist/`: `kdmid-person-autofill.zip` для распаковки и `kdmid-chrome-web-store.zip` для загрузки в магазин. Python 3 требуется только для упаковки.

Тесты используют встроенный тестовый раннер Node.js и jsdom. Они проверяют заполнение полей, сохранение роли участника, даты, зависимые паспортные поля, замену данных, шифрование, перенос старых профилей, блокировку, параллельную запись, поиск стран, экспорт и импорт. Структура портала описана в [docs/portal-fields.md](docs/portal-fields.md) на английском.

## Ограничения прототипа

Переходы по порталу, зависимые поля документов и список стран проверены на живом сайте. Полное заполнение заявления установленным расширением ещё требует ручной проверки. Неполные даты рождения в редакторе не поддерживаются. При изменении формы портала может потребоваться обновление расширения.
